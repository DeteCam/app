# 주소 계약 (앱 ↔ 수신기)

앱이 부르는 수신기(허브)의 주소다. **이 문서가 기준이다.** 허브 프로그램은 이 표에 맞춰 고친다 (receiver 스펙 006). 표가 바뀌면 `net/ReceiverApi.kt` 와 같은 PR 에서 고친다.

- 허브의 Wi-Fi: 이름 `DeteCam-RX`, 주소 `http://192.168.4.1`. 인터넷은 없다.
- 모두 JSON. 좌표는 방 좌표계의 m, z 가 위. 방 좌표계는 첫 번째로 등록한 패널이 정한다 (그 패널의 마커가 원점 근처).
- 허브는 한 번에 한 가지 일만 한다. 하는 중에 다른 일을 시키면 409. `/api/stop` 만 언제나 받는다.

## 주소

| 주소 | 하는 일 | 앱에서 쓰는 곳 |
|---|---|---|
| `GET /api/status` | 상태 한 벌: `state`(idle·busy·error), `prompt`(한 줄 안내), `devices`(기기 표), `panels`(패널 표), `locate`(재는 중이면 대상과 쌓은 수) | 1초마다 |
| `POST /api/watch` `{"minutes","walk"}` | 점검 시작: 기준선을 잡고 엿듣는다. `walk` 가 참이면 애매할 때 걷기 확인을 시킨다 | 찾기 단추 |
| `POST /api/mine` `{"mac"}` | 내 기기로 표시 (점수에서 뺀다) | 기기 화면 |
| `POST /api/identify` `{"mode":"walk"}` | 걷기 확인 (약 55초). 결과는 기기 표의 `verdict` | 애매할 때 |
| `POST /api/target` `{"mac","ch"}` | 자리를 찾을 기기를 고른다 | 기기 화면 |
| `GET /api/marker` | 패널마다 마커 귀의 좌표 (패널 좌표, m) | 자리 등록 |
| `POST /api/pose` `{"panel","p","q"}` | 패널의 자리 `p`[x,y,z] 와 방향 `q`[w,x,y,z] (방 좌표) | 자리 등록 |
| `POST /api/seats` `{"rows","cols","pitch","first","last"}` | 교실 자리표. 첫 자리와 끝 자리 두 점과 줄·칸 수로 자리 좌표를 만든다 | 교실 설정 |
| `POST /api/room` `{"planes":[{"c","n","w","h"}]}` | 방의 겉면 (ARCore 평면: 가운데, 법선, 폭, 높이). 허브가 20 cm 간격의 후보 점을 만든다 | 방 훑기 |
| `POST /api/locate` `{"run"}` | 재기 시작(`true`)·멈춤(`false`). 패널은 대상이 보낼 때마다 잰다 | 결과 화면 |
| `GET /api/top` | 후보 셋: `[{"p","seat","prob"}]`, 쌓은 전송 수 `n`, 믿음 `confidence`, 다음 할 일 `next` | 결과 · AR |
| `GET /api/health` | 배터리, 온도, 패널마다 연결·마지막으로 잰 때 | 정비 |
| `POST /api/stop` | 멈춤 | 모든 화면 |

## 예

```json
GET /api/status
{"state":"busy","prompt":"카메라로 보이는 기기 1대. 자리를 찾는 중 (전송 3번)",
 "devices":[{"mac":"aa:bb:cc:dd:ee:ff","ch":6,"band":"2.4","per_s":92.1,"rssi":-47,"score":7,"level":"camera",
             "reasons":["새로 나타남","올려 보내는 양이 많음","꾸준히 보냄"]}],
 "panels":[{"id":"A","connected":true,"pose":true},{"id":"B","connected":true,"pose":true}],
 "locate":{"target":"aa:bb:cc:dd:ee:ff","n":3}}

GET /api/top
{"n":3,"confidence":0.71,"next":"그대로 두면 더 좁혀집니다",
 "top":[{"p":[2.1,4.4,0.80],"seat":14,"prob":0.52},{"p":[3.2,4.4,0.80],"seat":15,"prob":0.21},{"p":[2.1,5.35,0.80],"seat":20,"prob":0.12}]}
```

## 바뀐 것

돌판 수신기([receiver-legacy](https://github.com/DeteCam/receiver-legacy), 태그 `plate-v2`)의 주소 가운데 모터와 관절에 관한 것(`/api/measure`, `/api/present`, `/api/home`, `/api/zero`, `/api/goto`, `/api/jog`, `/api/off`)과 구역 표시(`/api/zone`, `/api/exam`)는 뺐다. 패널은 움직이지 않고, 결과는 후보 셋(`/api/top`) 하나로 모았다.
