# 앱 ↔ 수신기 주소(API) 계약 (초안)

- 상태: 초안 갱신 (2026-11-25). 수신기 펌웨어가 없으므로 구현하며 고친다. 바꾸면 이 문서와 receiver를 같은 변경에서 고친다.
- 연결 (AGENTS.md R9): 측정 중에는 제어용 무선을 완전히 정지(Burst-TDM)하여 AX210 측정 채널 포화를 막고, 버스트 직후 요약 데이터만 전송한다. 전송 경로는 호스트 UART BLE 또는 내부 UART ESP32 브리지(Wi-Fi AP / BLE), HTTP + WebSocket(`v1`).

| 주소 | 방법 | 설명 | 주요 내용 |
|---|---|---|---|
| `/api/v1/status` | GET | 수신기 상태 | 배터리, AX210 · PE42482 스위치 상태, 보정표 버전, 제어 무선 모드 |
| `/api/v1/room` | PUT | 방 지도 전달 | 방 크기(가로 · 세로 · 높이), 눈에 보이는 대형 금속 반사체 1~2면(칠판 · 거울 · 사물함, 선택), 수신기 위치 · 방향, 측정 자리 번호 |
| `/api/v1/devices` | GET | 주변 기기 목록과 카메라 판별 결과 | 기기별 임시 번호(MAC은 화면에 일부만), 채널, 802.11b 폴백 여부, 수동 L2/PHY 카메라 확률, 근거 |
| `/api/v1/stimulus` | POST | 자극 구간 표시 (선택, 비시험장 보조 전용) | 시작 · 끝 시각, 종류(조명 · 움직임). 시험장에서는 쓰지 않음 |
| `/api/v1/measure` | POST | 한 자리 측정 시작 | 대상 기기, 측정 버스트 시간(Burst-TDM) → 측정 번호 |
| `/api/v1/measure/{id}` | GET | 측정 결과 | 방향(방위각 · 고도각), 신뢰도(방향 분포 퍼짐), 실패 여부(802.11b CSI 불가 등)와 이유 |
| `/api/v1/calibrate` | POST | 현장 보정 | 송신기 위치들(폰 AR 좌표)과 측정 → 보정된 수신기 방향 · 위치 |
| `/api/v1/zone` | GET | 여러 자리를 합친 의심 구역 | 신뢰도 가중 2자리 결합 구역 모양, 포함 확률 |
| `/ws/v1/live` | WS | 진행 상황 · 경보 | 버스트 완료 직후 진행률, 새 카메라 의심 경보 |
