# DeteCam 6.0 (`Nano-2 AI`) 앱 ↔ 수신기 주소·API 계약

> 2기 포켓 노드(`node-1`, `node-2`, `NanoPi R5C`) + 마스터 앱 간 REST/WebSocket 계약.

| 엔드포인트 | 메서드 | 설명 | 주요 페이로드 |
|---|---|---|---|
| `/api/v6/ar-opa/recommend` | `POST` | AR 스캔 방·장애물 → 최적 2기 벽면 위치·Pan/Tilt 클릭 추천 | `room_dims`, `obstacles`, `k=2`, `mirror_aware=true` → `nodes[2]`, `virtual_mirror_coverage_pct` |
| `/api/v6/nodes/auto-verify` | `POST` | 3초 상호 전파 교정 (숨은 철근·배관 반사 감지) | `mutual_aoa_err_deg[2]`, `ambient_cv_f[2]` → `ok`, `placement_score`, `warnings` |
| `/api/v6/ai/camguard` | `POST` | `CamGuard-Net` + 5초 `CamLoPA` 인과 카메라 판별 | `seq_4x60`, `causal_corr`, `hidden_ap`, `legacy_1x1` → `is_camera`, `prob_camera` |
| `/api/v6/localize/ma-pinn` | `POST` | `ReconCovNet-v4` + Bayesian `MA-PINN` + `ΔP_12` + 선택적 폰 보행 융합 | `csi_nodes[2]`, `phone_walk_rssi?` → `est_xyz`, `raps_90_indices`, `mirror_rays` |
| `/ws/v6/live` | `WS` | 실시간 10 Hz `RAPS 90%` AR 신뢰 구역 & 탐지 경보 스트림 | `target_mac`, `prob_cam`, `ar_zone_xyz`, `confidence_90` |
