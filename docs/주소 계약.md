# 주소 계약 (앱 ↔ DeteCam 5.0 Palm-12 수신기)

앱이 부르는 수신기(마스터 노드 `Radxa ROCK 3A`)의 REST API 기준 문서입니다.

- 접속 Wi-Fi: `DeteCam-RX`, 기본 주소: `http://192.168.4.1` (오프라인 로컬 동작).
- 모든 좌표는 방 좌표계(단위 `m`, `+Z` 위), 모든 요청·응답은 JSON입니다.
- `Palm-12` 112×112 mm 통합 RF 보드는 **2.4 GHz와 5 GHz 전 채널(`locate: true`)을 동일하게 지원**합니다.

## API 목록

| 주소 | 역할 | 주요 요청 / 응답 필드 |
|---|---|---|
| `GET /api/status` | 전체 상태 1초 폴링 | `state`, `prompt`, `devices[]` (`mac`, `ch`, `band`, `locate`, `score`, `level`, `reasons[]`), `nodes[]` (3기 연결·자세·배터리), `cellular` (`AD8317×3` 교차 차감), `ble` (무료 BLE 구역) |
| `POST /api/room` | ARCore 방 치수·장애물 등록 | `{"dims_m":[L,W,H], "obstacles":[{"box":[x0,x1,y0,y1,z0,z1],"kind","loss_db","refl"}], "roi":[[x,y,z],...]}` |
| `POST /api/opa/recommend` | **AR-OPA 벽면 위치 + Pan/Tilt 클릭 각도 계산** | 응답: `nodes[]` (`id`, `wall`, `pos_m`, `pan_deg`, `tilt_deg`, `aim`, `mount`, `guide_ko`), `expected_p90_crlb_m`, `los2_coverage_pct` |
| `POST /api/verify/mutual` | **3초 Auto-Verify 상호 전파 교정** | 응답: `ok`, `placement_score` (0~100), `mutual_aoa_err_deg[3]`, `ambient_cv_f[3]`, `warnings[]` |
| `POST /api/pose` | ArUco 마커 기반 노드 실제 자세 등록 | `{"node_id":1, "p":[x,y,z], "q":[w,x,y,z], "pan_deg":30, "tilt_deg":-15}` |
| `POST /api/watch` | 1단계 수동 감시 시작 | `{"minutes":5}` |
| `POST /api/mine` | 내 기기 제외 등록 | `{"mac":"aa:bb:cc:11:22:33"}` |
| `POST /api/stimulus` | **2단계 인과 자극 검정** (조명 5초 점멸 / 보행) | `{"mode":"light_toggle" \| "walk", "duration_s":15}` → 응답: 기기별 `ratio_up`, `triggered` |
| `POST /api/target` | 위치 추적 대상 카메라 선택 (2.4/5 GHz 모두 허용) | `{"mac":"00:12:34:aa:bb:cc", "ch":44}` |
| `POST /api/locate` | `TriF v12` 실시간 3D 위치 추정 시작/중지 | `{"run":true}` |
| `GET /api/raps` | **RAPS 90% 통계 보장 AR 신뢰 구역** | `n_packets`, `coverage_guarantee`: `0.90`, `mirror_anchors_active`, `zone_pts[]`, `top_seats[]` (`seat`, `prob`), `confidence` |
| `GET /api/cellular` | **3노드 `AD8317` LTE/5G 교차 차감 경보** | `detected`, `max_rise_db`, `closest_node`, `node_peaks_db[3]` |
| `GET /api/ble` | 3노드 내장 BLE 5.3 무료 구역 추정 | `count`, `new_count`, `zone_center_m`, `strongest_node` |
| `POST /api/stop` | 즉시 정지 (항상 최우선 처리) | `{}` |

## 응답 예시 (`POST /api/opa/recommend` & `GET /api/raps`)

```json
{
  "nodes": [
    {"id": 1, "wall": "왼벽", "pos_m": [0.06, 3.6, 2.0], "pan_deg": -30, "tilt_deg": -15,
     "mount": "벽면 자석·나노겔 스위블", "guide_ko": "왼벽 2.0m (자석·나노겔 벽부착) → 좌우 왼쪽 2칸(-30°), 상하 아래 1칸(-15°)"}
  ],
  "expected_p90_crlb_m": 0.89,
  "los2_coverage_pct": 94.2
}
```
