# 주소 계약 (앱 ↔ 수신기)

앱이 부르는 수신기의 주소다. 기준은 receiver 저장소의 [혼자 동작](https://github.com/DeteCam/receiver/blob/main/docs/%ED%98%BC%EC%9E%90%20%EB%8F%99%EC%9E%91.md) 5절이고, 여기에는 앱이 쓰는 것만 옮겨 둔다. 수신기 쪽이 바뀌면 이 표와 `net/ReceiverApi.kt` 를 같이 고친다.

모두 JSON. 좌표는 m, z 가 위. 각은 위에서 볼 때 +x 에서 반시계. 수신기는 한 번에 한 가지 일만 한다 (하는 중에 다른 일을 시키면 409). `/api/stop` 만 언제나 받는다.

| 주소 | 앱에서 쓰는 곳 |
|---|---|
| `GET /api/status` | 1초마다. `status.state`(idle·busy·error), `status.prompt`, 기기 표, 잰 자리들 |
| `GET /api/health` | 정비 화면: 전압 경고, 온도, 관절 각 |
| `POST /api/stop` | 멈춤 단추 |
| `POST /api/detect` | 찾기 1단계. 끝나면 `survey`(기기 표: `mac` `ch` `per_s` `rssi` `candidate` `role` `ssid` `note`) |
| `POST /api/config` `{"ch","mac"}` | 볼 기기 고르기 |
| `POST /api/identify` `{"mode"}` | 걷기 확인 (`walk` 55초). 결과 `verdict`(camera·unclear·quiet) |
| `POST /api/measure` `{"plan","pose","spot"}` | 한 자리 재기 |
| `POST /api/pose` `{"index","pose"}` | 마커로 구한 수신기 자리 알려 주기 |
| `POST /api/room` `{"lo","hi"}` | 찾을 범위 |
| `GET /api/zone` | 추정 구간: `centre` `box` `cells` `length_m` `confidence` `verdict` `next` |
| `POST /api/exam` `{"seats","spots","front"}` / `GET /api/exam` | 시험장 모드 켜기 / 자리 후보 `top`, `next`, `seats` |
| `GET /api/marker` | 등판 마커 귀의 좌표 |
| `POST /api/present` | 마커를 보여 주는 자세 |
| `POST /api/home` `/api/zero` `/api/goto` `/api/jog` `/api/off` | 정비 화면 |
