# 앱 ↔ 수신기 주소(API) 계약 (초안)

- 상태: 초안 (2026-11-24). 수신기 펌웨어가 없으므로 구현하며 고친다. 바꾸면 이 문서와 receiver를 같은 변경에서 고친다.
- 연결: 수신기가 만드는 Wi-Fi 접속점 또는 같은 네트워크, HTTP + WebSocket. 버전은 경로의 `v1`.

| 주소 | 방법 | 설명 | 주요 내용 |
|---|---|---|---|
| `/api/v1/status` | GET | 수신기 상태 | 배터리, AX210 · 스위치 상태, 보정표 버전 |
| `/api/v1/room` | PUT | 방 지도 전달 | 방 크기(가로 · 세로 · 높이), 큰 가구 면(선택), 수신기 위치 · 방향, 측정 자리 번호 |
| `/api/v1/devices` | GET | 주변 기기 목록과 카메라 판별 결과 | 기기별 임시 번호(MAC은 화면에 일부만), 채널, 카메라 확률, 근거 |
| `/api/v1/stimulus` | POST | 자극 구간 표시 | 시작 · 끝 시각, 종류(조명 · 움직임) |
| `/api/v1/measure` | POST | 한 자리 측정 시작 | 대상 기기, 측정 시간 → 측정 번호 |
| `/api/v1/measure/{id}` | GET | 측정 결과 | 방향(방위각 · 고도각), 신뢰도(방향 분포 퍼짐), 실패 여부와 이유 |
| `/api/v1/calibrate` | POST | 현장 보정 | 송신기 위치들(폰 AR 좌표)과 측정 → 보정된 수신기 방향 · 위치 |
| `/api/v1/zone` | GET | 여러 자리를 합친 의심 구역 | 구역 모양, 포함 확률 |
| `/ws/v1/live` | WS | 진행 상황 · 경보 | 측정 진행률, 새 카메라 의심 경보 |
