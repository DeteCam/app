# SPEC-002: 방 지도와 AR 표시

- 상태: 명세 갱신 (2026-11-25)
- 기준: docs AGENTS.md G3, 7.4절

## 1. 무엇을, 왜
수신기가 계산한 방향과 의심 구역을 실제 방 위에 겹쳐 보여 준다. 방향 계산에 필요한 방 크기, 눈에 보이는 대형 금속 반사체(칠판 · 거울 · 사물함) 위치, 수신기 위치도 폰 AR로 얻는다.

## 2. 요구사항

| 번호 | 요구사항 | 수용 기준 |
|---|---|---|
| FR-1 | 방 지도 · 대형 반사체 | ARCore 평면 인식으로 방 크기(줄자 값과 25 cm 이내 목표)와 눈에 보이는 대형 금속 반사체 1~2면(칠판 · 거울 · 사물함 줄, 선택)을 등록 |
| FR-2 | 수신기 위치 · 방향 | 수신기를 화면에서 찍어 위치와 방향을 등록. 방향 오차 3° 이내 목표(현장 보정으로 보완) |
| FR-3 | 방향 부채꼴 | 수신기에서 나가는 방향과 신뢰도에 따른 폭 |
| FR-4 | 의심 구역 | 두 자리 이상을 신뢰도 가중 결합한 구역. 실제 카메라 포함 비율 ≥ 90%, 구역 크기 함께 보고 |
| FR-5 | 표시 원칙 | "의심"으로 표시, 측정 실패(802.11b CSI 불가 등) · 낮은 신뢰도를 숨기지 않음 |

## 3. 범위 밖
수신기 배치를 자동으로 추천하는 기능(v6의 AR-OPA-2)은 근거가 확인될 때까지 뺀다. 놓는 자리는 "앞쪽 · 높은 모서리" 같은 안내 문구로 시작한다.
