# SPEC-002: 방 지도와 AR 표시

- 상태: 명세 (2026-11-26)
- 기준: docs AGENTS.md G3, 7.4절, R10

## 1. 무엇을, 왜

수신기가 계산한 방향과 의심 구역을 실제 방 위에 겹쳐 보여 준다. 방향 · 위치 계산에 필요한 방 크기, 수신기를 둔 자리의 위치 · 방향, 시험실의 책상 후보도 폰 AR로 얻는다.

## 2. 요구사항

| 번호 | 요구사항 | 수용 기준 |
|---|---|---|
| FR-1 | 방 지도 | ARCore 평면 인식으로 방 크기와 벽 · 천장 · 바닥 면을 얻음. 줄자 값과 25 cm 이내(방향 계산이 25 cm 오차까지 견딘다는 계산 근거, 실측으로 다시 확인) |
| FR-2 | 수신기 위치 · 방향 | 자리마다 수신기를 화면에서 찍어 위치와 방향을 등록. 방향 오차 3° 이내 목표(현장 보정으로 보완) |
| FR-3 | 책상 후보(시험실) | 평면 인식과 사람 인식으로 책상 후보를 자동으로 찾음. 책상 중심 오차 0.10 m 이내 목표(계산이 가정한 값). 교실에서 줄자 값과 견줘 확인하고, 넘으면 그 오차로 다시 계산 |
| FR-4 | 방향 부채꼴 | 합친 위치를 가장 믿을 만한 자리에서 바라본 방향과, 믿을 만한 정도에 따른 폭. 한 자리 결과만 있을 때는 "한 자리 결과"로 따로 표시 |
| FR-5 | 의심 구역 | 두 자리 이상을 합친 구역. 실제 카메라를 포함하는 비율 90% 이상, 구역 크기를 함께 보고 |
| FR-6 | 의심 책상(시험실) | 책상 후보 위에 의심 책상 3곳을 표시 |
| FR-7 | 표시 원칙 | "의심"으로 표시. 측정 실패, 믿기 어려운 자리, CSI를 얻을 수 없는 기기를 숨기지 않음 |

## 3. 범위 밖

- 좌석 배치도 · 응시자 자리 · 책상 좌표를 미리 입력하는 기능(R10)
- 수신기 놓을 자리를 자동으로 추천하는 기능(v6의 AR-OPA-2): 근거가 확인될 때까지 뺀다. "마주 보는 두 벽부터", "시험실은 앞벽 두 자리" 같은 안내 문구로 시작한다.
