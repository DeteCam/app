# SPEC-001: 수신기 조종

- 상태: 명세 (2026-11-24)
- 기준: docs AGENTS.md R3(돌아다니지 않음), 원칙 4(수신기 혼자 동작)

## 1. 무엇을, 왜
노트북 없이 폰 하나로 스위치 고리 수신기(1~2기)의 모든 동작을 시킨다.

## 2. 요구사항

| 번호 | 요구사항 | 수용 기준 |
|---|---|---|
| FR-1 | 연결 | 폰에서 수신기를 찾아 10초 안에 연결 |
| FR-2 | 기기 목록 | 주변 기기와 카메라 확률을 보여 주고 대상 기기를 고름 |
| FR-3 | 자극 안내 | 조명 끄기 등 자극 시작 · 끝을 수신기에 알림 |
| FR-4 | 측정 | 한 자리 측정 시작 · 중지, 진행률, 실패 이유 표시 |
| FR-5 | 현장 보정 | 위치를 아는 송신기(폰 또는 ESP32)를 몇 곳에 두도록 안내하고 결과를 수신기에 보냄 |
| FR-6 | 두 번째 자리 | 신뢰도가 낮으면 다른 모서리로 옮겨 다시 재도록 안내 |
| NFR-1 | 상태 | 배터리, 수신기 상태 표시 |

주소는 [`docs/주소 계약.md`](../../docs/주소%20계약.md)를 따른다.
