# SPEC-001: 수신기 조종과 측정 안내

- 상태: 명세 (2026-11-26)
- 기준: docs AGENTS.md R3(수신기 1기를 여러 자리로), R9(기기 사이는 무선), R10 · R11(좌석 정보 입력과 좌석마다 기기 금지)

## 1. 무엇을, 왜

노트북 없이 폰 하나로 스위치 고리 수신기 1기의 모든 동작을 시킨다. 수신기는 여러 자리에 차례로 옮겨 두고 재므로, 앱이 "어디에 두고, 언제 재고, 언제 멈출지"를 안내한다.

## 2. 요구사항

| 번호 | 요구사항 | 수용 기준 |
|---|---|---|
| FR-1 | 연결 | 폰에서 수신기를 찾아 10초 안에 연결(BLE). 측정 중 연결이 끊기면 다시 붙고 진행 상태를 이어 받음 |
| FR-2 | 기기 목록 | 주변 기기와 카메라 확률을 보여 주고 대상 기기를 고름. CSI를 얻을 수 없는 기기는 그렇게 표시 |
| FR-3 | 자극 안내 | 시험실 밖에서만, 조명 끄기 등 자극 시작 · 끝을 수신기에 알림 |
| FR-4 | 자리 등록 | 수신기를 둔 자리마다 자리 번호, 위치 · 방향(AR), 놓인 면(유전체 / 금속)을 수신기에 보냄 |
| FR-5 | 측정 | 한 자리 측정 시작 · 중지, 세 자세 진행률, 실패 이유 표시 |
| FR-6 | 자리 결과 안내 | 자리마다 믿을 만한 정도를 보여 주고, 믿기 어려우면 다른 자리에서 다시 재라고 안내 |
| FR-7 | 더 재기 안내 | 합친 결과가 아직 퍼져 있으면 자리를 더 재라고 안내하고, 충분하면 멈추라고 알림. 지금까지 잰 자리 수를 보여 줌 |
| FR-8 | 시험실 순서 | 시험실에서는 앞벽 두 자리를 모두 재도록 안내. 한 자리만 잰 결과는 "부족"으로 표시 |
| FR-9 | 현장 보정 | 위치를 아는 송신기(폰 등) 한두 개를 두도록 안내하고 결과를 수신기에 보냄. 좌석마다 두는 기기가 아님 |
| NFR-1 | 상태 | 배터리, 수신기 상태(AX210 · 스위치 · 끄덕이기) 표시 |
| NFR-2 | 입력 제한 (R10) | 좌석 배치도 · 응시자 자리 · 책상 좌표를 입력받는 화면을 만들지 않음 |
| NFR-3 | 움직임 (R3) | 재는 동안 사용자가 걷거나 폰을 들고 움직이게 하는 절차를 넣지 않음 |

주고받는 내용은 [`docs/주소 계약.md`](../../docs/주소%20계약.md)를 따른다.

## 3. 아직 정하지 않은 것

- 시험 중에 수신기를 옮기는 횟수를 줄이는 운영 방법(쉬는 시간에 두 번째 자리, 시험 전에 두 자리를 다 재기 등). docs 현재_방향.md U10에서 정한다.
- 다음에 잴 자리를 앱이 골라 주는 기능. 지금은 미리 정한 순서(마주 보는 두 벽부터)로 안내한다.
