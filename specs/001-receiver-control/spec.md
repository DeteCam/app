# SPEC-001: 수신기 조종

- 상태: 명세 갱신 (2026-11-25)
- 기준: docs AGENTS.md R3(돌아다니지 않음), R9(기기 사이 무선 · 측정 무간섭), 원칙 4(수신기 혼자 동작)

## 1. 무엇을, 왜
노트북 없이 폰 하나로 스위치 고리 수신기(1~2기)의 모든 동작을 무선으로 시킨다. 측정 버스트(1.5~2초) 중에는 제어 무선 송신을 멈추어(Burst-TDM) AX210 수신 채널 간섭을 막는다.

## 2. 요구사항

| 번호 | 요구사항 | 수용 기준 |
|---|---|---|
| FR-1 | 무선 연결 (R9) | 폰에서 UART BLE 또는 내부 UART ESP32 브리지로 수신기를 찾아 10초 안에 연결. 측정 버스트 중에는 제어 무선 무송신 |
| FR-2 | 기기 목록 | 수동 L2/PHY 판별 기준 주변 기기와 카메라 의심 확률 · 근거를 보여 주고 대상 기기를 고름 |
| FR-3 | 자극 안내 (선택) | 비시험장(숙소 등)에서만 조명 끄기 등 자극 보조 구간을 선택적으로 표시. 시험장에서는 사용하지 않음 |
| FR-4 | 측정 | 한 자리 또는 두 자리 동시 측정 시작 · 중지, 버스트 완료 진행률, 실패 이유(802.11b CSI 불가 · 낮은 신뢰도 등) 표시 |
| FR-5 | 현장 보정 | 위치를 아는 송신기(폰 또는 ESP32)를 몇 곳에 두도록 안내하고 결과를 수신기에 보냄 |
| FR-6 | 두 번째 자리 | 신뢰도가 낮거나 1기 순차 측정 시 다른 모서리로 옮겨 두 번째 자리를 재도록 안내 |
| NFR-1 | 상태 | 배터리, 수신기 · 스위치 상태, 제어 무선 연결 상태 표시 |

주소는 [`docs/주소 계약.md`](../../docs/주소%20계약.md)를 따른다.
