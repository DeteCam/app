# 002 AR 의심 구역 표시 — 계획

## 구조

- **ARCore** (Augmented Images + 평면 인식 + 앵커). 그리기는 **SceneView**(Filament 기반)로 하고, 구역은 칸마다 상자를 그리지 않고 겉면만 뽑아 메시 하나로 만든다 (칸 1,500개 → 삼각형 수천 개).
- **좌표 잇기**: 마커 귀 4개의 받침 기준 좌표(수신기가 관절 각으로 계산해 준다)와 ARCore 가 준 마커 자세 → 받침 좌표계 ↔ AR 세계 좌표계 변환 행렬. 수신기를 옮길 때마다 새 변환을 구하고, 방 좌표계는 첫 자리의 받침으로 고정한다.
- **방 범위**: ARCore 평면(바닥·벽)에서 방 크기를 어림해 `/api/room` 으로 보낸다. 시험장에서는 좌석표의 간격과 첫 자리·끝 자리 두 점을 AR 에서 찍어 좌석 좌표를 만든다.

## 데이터 흐름

```
/api/marker ─┐                         ┌─ /api/pose (받침 자리·방향)
             ├─ MarkerRegistrar ───────┤
ARCore 자세 ─┘                         └─ RoomFrame (방 좌표 ↔ AR 세계)
/api/zone, /api/exam ── ZoneMesh / SeatBadges ── SceneView
```

## 검증

- 마커 인식 거리·각도별 성공률과 자세 오차를 줄자·각도기로 잰다 (0.5~3m, 정면~60°).
- 구역 메시 만들기는 단위 시험 (칸 목록 → 겉면 삼각형 수, 닫힌 메시인지).

## 위험

- 어두운 방·번들거리는 등판에서 마커가 안 읽힌다 → 마커는 무광 종이, 실패하면 FR-4(손으로 찍기).
- ARCore 가 지원하지 않는 기종 → 평면도 화면만으로도 끝까지 쓸 수 있게 한다.
