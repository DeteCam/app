# 002 AR 의심 구역 표시

## 배경

수신기가 내는 답은 공간 속의 구역(몰카 찾기) 또는 자리 후보(시험장)다. 평면도만으로는 "그래서 저 화분인가, 그 옆 시계인가"를 알기 어렵다. 폰 카메라 화면 위에 구역을 겹쳐 그리면 사용자가 그 안의 물건을 바로 확인할 수 있다. AR 은 **구역을 보여 주는 데만** 쓴다 (길 안내는 글로 한다).

두 좌표계를 맞추는 것이 핵심이다: 수신기는 자기 받침을 원점으로 방향을 재고, 폰은 ARCore 의 세계 좌표를 쓴다. 수신기 등판의 종이 마커를 폰이 읽어 둘을 잇는다.

## 사용자 시나리오

1. 수신기를 놓고 '자리 등록'을 누르면 수신기가 등판(마커)을 보여 주는 자세를 잡는다. 폰으로 비추면 1~2초 안에 "등록됨"이 뜬다.
2. 측정이 끝나고 'AR 로 보기'를 누르면, 방 안에 반투명한 덩어리(추정 구간)가 떠 있다. 가까이 가면 덩어리 안의 물건이 보인다.
3. 시험장에서는 자리 후보 3곳의 책상 위에 1·2·3 순위 표시가 뜬다.

## 요구사항

| 번호 | 내용 |
|---|---|
| FR-1 | 마커(`GET /api/marker` 의 귀 좌표)를 ARCore Augmented Images 로 읽어 수신기 받침의 자리와 향한 쪽을 구하고 `POST /api/pose` 로 보낸다 |
| FR-2 | `GET /api/zone` 의 칸 목록(10cm)과 상자를 AR 공간에 반투명 부피로 그린다. 믿음이 낮으면 색을 옅게 한다 |
| FR-3 | `GET /api/exam` 의 자리 후보 3개를 책상 높이에 순위 표시로 그린다 |
| FR-4 | 마커가 안 읽히면 평면도에서 수신기 자리를 손으로 찍는 길을 둔다 |
| FR-5 | 수신기를 옮길 때마다 자리 등록을 다시 하고, 앞서 잰 자리들과 같은 좌표계에 유지한다 (ARCore 앵커) |
| NFR-1 | 마커로 구한 수신기 자리의 오차: 2m 거리에서 위치 5cm, 방향 3° 안 (시뮬레이션이 가정한 값) |
| NFR-2 | 구역을 그릴 때 화면 30fps 이상 (칸 1,500개까지) |

## 수용 기준

- 줄자로 잰 수신기 자리와 앱이 구한 자리의 차이: 10번 가운데 9번이 NFR-1 안.
- 수신기를 세 곳으로 옮기며 등록한 뒤, 첫 자리의 AR 표시가 5cm 넘게 밀리지 않는다.
- 가짜 수신기가 준 구역을 실제 방에 띄웠을 때, 정해 둔 점(책상 모서리 등)이 구역 안에 보인다.

## 범위 밖

- 화면 속 물체 인식(의심 물체 순위)은 확장 기능으로 둔다. 걷는 길 안내를 AR 화살표로 그리지 않는다.
