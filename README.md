# DeteCam app — 스마트폰 앱

수신기를 무선으로 조종하고, 폰 AR로 방 지도를 만들며, 여러 자리에서 잰 결과를 합친 카메라 방향과 의심 구역을 AR 화면에 보여 주는 앱입니다.

> 상태(2026-11-26): **명세 단계.** 수신기 1기를 여러 자리로 옮겨 가며 재는 운영에 맞춰 스펙과 주소 계약을 고쳤습니다. 작업 기준은 [docs/AGENTS.md](https://github.com/DeteCam/docs/blob/main/AGENTS.md), 지금 고른 설계는 [docs/현재_방향.md](https://github.com/DeteCam/docs/blob/main/현재_방향.md)입니다.

## 기능

1. **방 지도**: ARCore로 바닥 · 벽 · 천장 평면을 잡아 방 크기를 얻는다. 시험실에서는 책상 후보도 평면 인식과 사람 인식으로 자동으로 찾는다. 좌석 배치도나 책상 좌표를 입력받지 않는다.
2. **자리 등록과 측정**: 수신기를 둔 자리마다 화면에서 수신기를 찍어 위치와 방향을 등록하고 측정을 시작한다. 수신기는 머리를 세 자세로 끄덕이며 잰다.
3. **측정 안내**: 자리마다 믿을 만한 정도를 보여 주고, 믿기 어려우면 다른 자리에서 다시 재라고 안내한다. 합친 결과가 아직 퍼져 있으면 자리를 더 재라고 안내한다.
4. **AR 표시**: 합친 위치를 가장 믿을 만한 자리에서 바라본 방향 부채꼴과 의심 구역을 보여 준다. 시험실에서는 의심 책상 3곳을 표시한다. 결과는 "의심"으로 표시한다.

사용자는 자리를 옮길 때만 움직이고, 재는 동안에는 돌아다니지 않는다. 폰은 방 지도를 만들 때, 자리를 등록할 때, 결과를 볼 때 쓴다.

## 쓰는 순서

| 순서 | 시험실 밖(숙소 · 화장실 · 탈의실 등) | 시험실(교실 · 강의실) |
|---|---|---|
| 1 | 방 지도 만들기 | 방 지도 만들기(책상 후보 자동 인식) |
| 2 | 마주 보는 두 벽부터 4곳을 차례로 잼 | 앞벽 두 자리를 모두 잼 |
| 3 | 앱이 안내하면 자리를 더 잼 | 옮기는 횟수는 가장 적게 |
| 4 | 방향 부채꼴과 의심 구역 확인 | 의심 책상 3곳 확인 |
